# Update Docs

Audit `docs/` (Astro + Starlight) against source and fix stale, stub or missing pages. The user may name a focus area; otherwise audit everything.

## Layout

- Pages: `docs/src/content/docs/{concepts,syntax,guides,reference,tutorial}/`
- Sidebar: `docs/astro.config.mjs` (static; `reference/` is autogenerated)
- Frontmatter schema (incl. tutorial `files`, `successCriteria`): `docs/src/content.config.ts` — read it, and copy an existing tutorial `.mdx` as the template.
- Code fences: ` ```pywire ` for `.wire`, plus `python`, `sh`, `html`, `json`.

## Source of truth

| Area | Path |
|------|------|
| Public API | `packages/pywire/src/pywire/__init__.py` |
| App class | `packages/pywire/src/pywire/runtime/app.py` |
| Page lifecycle hooks | `packages/pywire/src/pywire/runtime/page.py` (e.g. `before_load`) |
| Events / event data | `packages/pywire/src/pywire/runtime/events.py` |
| Form validation | `packages/pywire/src/pywire/runtime/validation.py` |
| Refs, expose, props | `packages/pywire/src/pywire/core/{refs,expose,props}.py` |
| Built-in components | `packages/pywire/src/pywire/components/` |
| Auth | `packages/pywire/src/pywire/auth/`, `packages/pywire-auth/` |
| Directives | `packages/pywire-parser/src/pywire_parser/directives/` (parse), `packages/pywire/src/pywire/compiler/directives/` (compile) |
| CLI | `packages/pywire-cli/src/pywire_cli/main.py` |
| Editor tooling | `packages/vscode-pywire/package.json`, `packages/pywire-language-server/`, `packages/prettier-plugin-pywire/` |
| Scaffolding | `packages/create-pywire-app/src/create_pywire_app/main.py` |

## Workflow

1. **Audit.** Read the source for the area, then the matching pages. Classify each feature: documented / stale / stub / missing. Never document an API signature you haven't read in source.
2. **Update.** Fix stale examples and prose; expand stubs (concept, example, common patterns, links); create missing pages and add them to the sidebar. Match the existing tone: concise, code-first.
3. **Verify.** `cd docs && pnpm format && pnpm lint:fix && pnpm build` — build must pass with zero errors.
4. **Commit** as `docs(pywire-docs): ...`.

Don't touch the tutorial engine (`docs/src/components/tutorial/`) or `astro.config.mjs` beyond sidebar entries.
