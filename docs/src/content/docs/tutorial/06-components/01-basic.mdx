Components in PyWire are just `.wire` files that are compiled into Python classes. You can import them into other pages or components using standard Python import syntax.

### Your Task

1.  Switch to `components/my_button.wire` in the file tree.
2.  Add a `<style scoped>` block to add a hover effect (e.g. `opacity: 0.8`) to the button.
3.  Add a second `<MyButton />` tag to the index page.
4.  Observe that the button in the preview updates immediately.

In PyWire, you explicitly import what you use, just like in Python. This makes it easy to know exactly where a component is coming from.

> Components can accept **props**, **children**, and **named snippets** — covered in the next lessons and in the dedicated *Snippets* section.
