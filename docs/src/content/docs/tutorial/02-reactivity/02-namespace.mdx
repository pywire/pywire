The `wire()` function accepts keyword arguments to create a reactive namespace. You can access and mutate properties using standard dot notation.

### Your Task

1.  In the `track_click` function, increment `user.clicks`.
2.  Click the button 3 times.

Wire namespaces (created with `wire(key=value, ...)`) group related state together while keeping everything reactive. Note: this is different from `wire({"key": "value"})` which creates a `WireDict` — a reactive dictionary. Both support dot-notation access, but namespaces are the preferred pattern for structured state.
