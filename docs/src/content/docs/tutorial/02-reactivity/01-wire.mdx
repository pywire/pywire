Reactivity in PyWire centers around the `wire()` primitive and the `.value` property for mutation.

### Your Task

1.  Initialize a reactive variable named `count` with a value of `0` using `wire(0)`.
2.  Inside the `increment` function, use **`count.value`** to add 1 to the count.
3.  Click the button until the count reaches **5**.

In PyWire, whenever you update `wire.value`, it triggers a UI patch! Note that in the template, you don't need `.value` for interpolation—`{count}` just works.
