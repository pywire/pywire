Snippets can take **parameters**. The component owns the iteration (or async logic, or conditional), and hands each value to the snippet body via named params.

This is the PyWire equivalent of React's "render props" pattern — but declarative and closer to the markup.

### Your Task

1. In `components/list.wire`, loop over `props.items` with a `<li $for={item in props.items}>` and render the snippet with `{$render row(item)}` inside each `<li>`.
2. In `pages/index.wire`, define the snippet with a parameter: `{$snippet row(todo)}...{/snippet}`. Inside the body, reference `todo['text']` and `todo['done']`.
3. Verify all three todos render as checkbox labels.

**Why this matters:** the component controls _how_ to iterate (order, pagination, virtualization, animation), and the caller controls _what_ each row looks like. No rigid inheritance; just a callable snippet.

Parameterless snippets are just `{$snippet name}...{/snippet}` — parens are optional when there are no params.
