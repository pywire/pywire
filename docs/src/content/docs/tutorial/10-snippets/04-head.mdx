`{$head}...{/head}` **teleports** its contents into the document's `<head>`, regardless of where in the component tree it appears. Pages, layouts, and components can all contribute — their fragments merge in the root `<head>`.

This means layouts don't need to know which page wants which `<meta>` tag. Each page declares what it needs, and PyWire sorts it out at render time.

### Your Task

1. In `pages/index.wire`, add a `{$head}...{/head}` block above the `<article>` that sets a `<title>` and a `<meta name="description">`.
2. Inspect the rendered HTML. The layout's `<title>My Blog</title>` should be replaced by the page's title; the layout's `<meta charset>` and `<meta viewport>` should still appear first.

### Merge rules

- **`<title>`**: the last `<title>` contributed by the render tree wins. Earlier titles are stripped out.
- **Everything else**: preserved in authored order. If the layout writes `<meta charset>` first, charset stays first — even if a nested component adds a title afterwards.

This makes `{$head}` safe for arbitrary composition: a shared component can drop in its own `<link rel="preload">` tag, and it'll slot in without wrecking the layout's charset or viewport meta.
