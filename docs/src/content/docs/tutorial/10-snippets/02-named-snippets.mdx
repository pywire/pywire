Children cover the default case, but real components often have **multiple named regions** — header, footer, sidebar, and so on. PyWire exposes these as **named snippets** that the parent defines and the component renders.

There are two `{$render}` forms:

- **Self-closing:** `{$render header(args)}` — calls the snippet and errors if nothing was supplied.
- **Paired:** `{$render header}Default{/render}` — the body is a **fallback** rendered only when the snippet isn't provided.

Inside a component's tags, `{$snippet name}...{/snippet}` is sugar for passing the snippet as a prop. It's equivalent to writing `<Card header={my_snippet} />` but keeps the markup inline.

### Your Task

1. In `components/card.wire`, replace the `<header>` comment with the paired fallback form `{$render header}Untitled{/render}`.
2. In `pages/index.wire`, replace the comment inside `<Card>` with `{$snippet header}Product Details{/snippet}`.
3. Verify the header shows **Product Details**, and that removing the snippet would fall back to **Untitled**.

Named snippets are just `Snippet` values — you can pass them explicitly via `header={some_snippet}`, compute them in Python, or reuse one snippet across multiple components.
