To use a component from a subdirectory, simply import it using Python's standard dot notation.

### Your Task

1.  In `pages/index.wire`, add a Python block at the top.
2.  Import `FancyButton` from `lib.ui.fancy_button`.
3.  Check the preview to see that `<FancyButton />` now correctly renders the fancy button.

This gives you full control over your project structure while keeping imports standard and predictable.
