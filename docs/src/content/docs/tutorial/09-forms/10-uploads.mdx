      ---
      from typing import Annotated
      from pydantic import BaseModel
      from pywire import form
      from pywire.forms import Upload, UploadField
      from pywire.storage import MemoryStore

      store = MemoryStore()

      class Avatar(BaseModel):
        image: Annotated[Upload, UploadField(accept="image/*", max_size="200 KB")]

      avatar = form(Avatar)
      result = wire("")

      async def save(data: Avatar):
        key = await data.image.save(store)
        result.value = f"Saved {data.image.filename} ({data.image.size} bytes) as {key}"
      ---
      <div>
        <h1>Avatar</h1>

        <form $bind={avatar} @submit={save}>
          <input $bind={avatar.image} />
          <p $if={avatar.image.error} style="color: red;">{avatar.image.error}</p>
          <progress data-pw-progress-for={avatar.image.html_id} max="1" value="0"></progress>
          <button type="submit">Save</button>
        </form>

        <p $if={result} style="color: green;">{result}</p>
      </div>

A field typed `Upload` takes a file. `UploadField` adds the rules: `accept` (types and extensions, as in HTML), `max_size` (bytes, or text like `"200 KB"`) and, for a `list[Upload]`, `max_files`.

### Your Task

1.  Import `Annotated` (`from typing import Annotated`) and `UploadField` (`from pywire.forms import Upload, UploadField`), then change the field to `image: Annotated[Upload, UploadField(accept="image/*", max_size="200 KB")]`.
2.  Under the input, add `<progress data-pw-progress-for={avatar.image.html_id} max="1" value="0"></progress>`.
3.  Pick a text file and click Save. The browser refuses it and says why. Then pick a small image and click Save.

With JavaScript on, a file uploads as soon as it is picked, while the user fills in the rest. The browser checks `accept`, `max_size` and `max_files` first and refuses with the same message the server would give (leave `novalidate` off so the browser can show it), and the `<progress>` element fills as the file goes up. The server checks every rule again on the bytes it received, and shows its error in `avatar.image.error`.

The handler gets an `Upload` with `filename`, `content_type`, `size`, `await read()`, `stream()` and `await save(store)`. `save` returns a random key. The browser's filename is never used as a key or path unless you pass it yourself. `accept` only checks the declared type and filename, so open the file yourself (with Pillow, for an image) before you trust its contents.

This tutorial saves into a `MemoryStore`. In a real app use `LocalStore("var/avatars")` for disk, or `ObjectStore.from_url("s3://bucket/avatars")` for S3, R2, GCS or Azure. They share one interface, so swapping one for another changes nothing else.
