Not every input needs a form and a model. `$bind` on an `<input>`, `<select>` or `<textarea>` with a wire keeps the two in step: the element shows the wire's value and editing the element writes the wire back.

### Your Task

1.  Bind the search box: `<input type="search" $bind={term} />`.
2.  Bind the number box: `<input type="number" $bind={limit} />`.
3.  Type `a` in the search box, then change the number of results.

The value is converted to the type the wire holds. `limit` holds an `int`, so it gets an `int`, and a value that doesn't convert (text in a number box) leaves the wire as it was. A wire holding a `bool` binds to a checkbox, and a wire holding a list binds to a group of checkboxes or a `<select multiple>`. Text boxes send after a pause in typing, and everything else sends on change.

The server only writes a wire through an element the page rendered, and never one that is `disabled`, `readonly` or `type="hidden"`. Nothing here is validated. When the value has rules, use a bound form.
