      from pydantic import BaseModel, Field
      from pywire import form

      class Signup(BaseModel):
        username: str = Field(min_length=3)

With JavaScript on, a bound form doesn't wait for the submit button. A text field is checked when the user leaves it. Once it shows an error, it is checked again as they type, so the message clears the moment the value is right. Checkboxes, radios and selects are checked when they change.

### Your Task

1.  This form was set to `validate="submit"`, which turns live checking off. Remove that argument so the line reads `signup = form(Signup)`.
2.  Type `ab` in the username box and click the age box. The error appears before you press Join.
3.  Type another letter. The error goes away as soon as the name has three.

Each check runs the whole model on the server, so a rule that reads `context=` or compares two fields gives the same answer as it will on submit. Only fields the user has been through show errors, and a form-level error waits for a submit. While a submit is in flight the form is marked `aria-busy` and a second submit is ignored, and when the answer has errors, focus moves to the first invalid field.
