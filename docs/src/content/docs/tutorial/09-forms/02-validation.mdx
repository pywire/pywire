      ---
      from pydantic import BaseModel, Field
      from pywire import form

      class Registration(BaseModel):
        username: str = Field(min_length=3)
        age: int = Field(ge=18)

      registration = form(Registration)
      result = wire("")

      def register(data: Registration):
        result.value = f"Registered {data.username} (age {data.age})"
      ---
      <div>
        <h1>Validation</h1>

        <form $bind={registration} @submit={register} novalidate>
          <div>
            <label for={registration.username.html_id}>Username</label>
            <input $bind={registration.username} />
            <span $if={registration.username.error} style="color: red;">
              {registration.username.error}
            </span>
          </div>
          <div>
            <label for={registration.age.html_id}>Age</label>
            <input $bind={registration.age} />
            <span $if={registration.age.error} style="color: red;">
              {registration.age.error}
            </span>
          </div>
          <button type="submit">Register</button>
        </form>

A bound form takes its rules from a Pydantic model. The model writes the HTML attributes (`required`, `minlength`, `min`, the input type), and the server validates every submit against the same model, so the rules hold even if someone edits the HTML.

### Your Task

1.  Create the form: `registration = form(Registration)`.
2.  On the `<form>`, add `$bind={registration} @submit={register} novalidate`. `novalidate` turns off the browser's own checks for this exercise so you can watch the server's.
3.  Replace each input with a bound one: `<input $bind={registration.username} />` and `<input $bind={registration.age} />`. The model supplies the name and type, so drop them.
4.  Below each input, show its error: `<span $if={registration.username.error}>{registration.username.error}</span>`.
5.  Submit a two-letter username or an age under 18 to see the errors.

`register` only runs when the submit is valid, and it receives a `Registration` instance rather than raw strings. In a real form, leave `novalidate` off: the browser then checks the same rules before sending, and the server checks them again.
