      ---
      from pydantic import BaseModel, Field
      from pywire import form

      class Profile(BaseModel):
        id: int
        name: str = Field(min_length=2)
        bio: str = ""

      stored = Profile(id=42, name="Ada Lovelace", bio="Wrote the first program.")

      profile = form(Profile, initial=stored)
      result = wire("")

      def save(data: Profile):
        result.value = f"Saved profile {data.id} for {data.name}"
      ---
      <div>
        <h1>Edit profile</h1>

An edit form starts from data you already have. Pass it as `initial`, either a model instance or a plain dictionary, and the inputs show those values.

### Your Task

1.  Change the form to `profile = form(Profile, initial=stored)`.
2.  Change the name and click Save.

Look at the result. The model needs an `id`, but the template never renders one, and the save still reports profile 42. A submit only reads the fields the page rendered with `$bind`. Any other field keeps its initial value, whatever the request says, so a visitor can't change `id` by adding it to the request. The same holds for a field rendered `disabled` or `readonly`.

To fill the form from a record you fetch when the page loads, call `profile.load(record)`. It replaces the initial values and clears any errors.
