      ---
      from pydantic import BaseModel, Field
      from pywire import form

      TAKEN = {"ada", "grace"}

      class Signup(BaseModel):
        username: str = Field(min_length=3)
        age: int = Field(ge=13)

      signup = form(
        Signup,
        messages={"age.rangeUnderflow": "You must be at least {ge} to join"},
      )
      result = wire("")

      def join(data: Signup):
        if data.username.lower() in TAKEN:
          signup.username.error = "That name is taken"
          return
        result.value = f"Welcome, {data.username}!"
      ---

Every rule comes with a message written for people, such as "Use at least 3 characters". You can reword any of them, and your handler can add errors the model can't know about, like a name that's already in use.

### Your Task

1.  Give `form()` a `messages` argument: `messages={"age.rangeUnderflow": "You must be at least {ge} to join"}`. The key is the field and the error code; `{ge}` is filled in from the rule (`13`). Leave out the field name (`"rangeUnderflow"`) to change the message for every field.
2.  In `join`, before the welcome message, check for a taken name. If `data.username.lower()` is in `TAKEN`, set `signup.username.error = "That name is taken"` and `return`.
3.  Submit an age of 10, then the name `ada`.

`join` only runs when the model accepts the submit, so the model's own errors never reach it. Setting an error in the handler marks the form invalid and shows the message next to the field, the same way a rule from the model does.
