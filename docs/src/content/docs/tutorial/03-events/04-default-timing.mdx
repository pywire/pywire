A handler on a text box would fire on every keystroke if PyWire sent every event. It doesn't: `input` on a text box, textarea or editable element is debounced by 250 ms, so the server gets one event after the user pauses. `scroll`, `wheel`, `resize` and pointer movement are throttled to one every 100 ms, always sending the last one. Clicks, submits and key presses go out at once, and they first send anything still waiting, so a button always runs on the latest text in the box next to it.

### Your Task

1.  Type a word quickly in the box and compare "Events received" with the number of letters. It should be much lower.
2.  Change `@input` to `@input.immediate` and type again. Now every keystroke is one event.

`.debounce.500ms` and `.throttle.100ms` set your own timing for one handler. To change a default for the whole app, pass `event_defaults` to `PyWire(...)`, for example `PyWire(event_defaults={"input": "debounce.400ms"})`.
