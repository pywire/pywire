To make components flexible, you can pass data to them using props. PyWire uses a type-safe `@props` decorator to define what data a component accepts.

### Your Task

1.  In `components/badge.wire`, import `props` from `pywire`.
2.  Define a `class Props` decorated with `@props`, adding `text: str` and `color: str = "gray"`.
3.  Replace "Text here" with **`{props.text}`** and `{color}` with **`{props.color}`**.
4.  Check the preview to see the "Admin" and "User" badges rendered with different colors.

Props are accessed via the `props` object in your template and are fully typed.
