Demos

Example apps built with pywire. Each one runs the latest code on the main branch, so it can be ahead of the release on PyPI.

  • Form builder

    Describe a form in a sentence and get a working one. An open model writes the fields, Jev picks each field's type and whether it's required, and pywire builds a Pydantic model and a live form from the result.

  • Stateless mode

    The page state travels with the browser in a signed snapshot, so any server can answer the next request. Includes keyed regions, optimistic updates and polling.

    Stateless, on Cloudflare Workers. Source

Stateless or stateful

A stateful pywire app keeps each page on the server and talks to the browser over a WebSocket. Shared state, like a chat room, updates every open tab at once. A stateless app keeps nothing between requests, so it runs on serverless platforms and scales without sticky sessions, at the cost of polling for shared changes. Read more about stateless mode.

More examples, including a FastAPI app with a database and a realtime chat, are in the examples folder.
